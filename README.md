# Learn Statistics with Phoebe

A foundational **statistics + probability** course, two tracks, one running brand. The statistics under machine learning and experimentation, taught so a leader can read it and a builder can compute it.

**Live site:** https://phoebefu6.github.io/learn-statistics-with-phoebe/

## Two tracks

- **Leader track (6 x 45 min, no code)** - read and interpret statistics without being fooled: mean vs median, probability and base rates, distributions, sampling and the Central Limit Theorem, confidence intervals, and hypothesis testing plus the fallacy gauntlet.
- **Builder track (10 x 45 min, Python)** - descriptive stats, probability and simulation, random variables, distributions in scipy, sampling and the CLT, estimation and maximum likelihood, confidence intervals, hypothesis testing, chi-square and ANOVA, and correlation, regression and fallacies - built from scratch with numpy, scipy, and statsmodels.

## The running brand: Lumen Skincare

Every session works on **Lumen Skincare**, a synthetic $18M direct-to-consumer skincare label. Its numbers are the teaching examples (order values averaging ~$74, ~3.2% checkout conversion, prior spend correlated ~0.6 with order value), and they line up exactly with [learn-experimentation-with-phoebe](https://phoebefu6.github.io/learn-experimentation-with-phoebe/) - so this course is the prequel that makes A/B testing click.

## Live statistics playground

Three zero-install, in-browser tools (`assets/stat-live.js`), embedded where they are taught:
- **Distribution sampler** - draw from normal / binomial / Poisson and watch samples fill the theoretical curve.
- **CLT convergence** - watch skewed order values average into a normal as the sample size grows.
- **Test and CI sandbox** - Lumen's 3.2% vs 3.6% A/B result: drag users-per-arm and watch the p-value and confidence interval move.
